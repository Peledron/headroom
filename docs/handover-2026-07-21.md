## How to resume

- Tests must run with .venv/bin/python (system python lacks opentelemetry).
  Exclude tests/test_hermes_passthrough_compression.py (missing respx) and the
  three native-Rust hangs above. pytest-timeout is installed, use
  --timeout=45 --timeout-method=signal so a native hang fails by name.
- Restart procedure after a code change: reinstall the uv tool from the tree
  (uv tool install --force --from the repo path with the all extra), then
  systemctl --user restart headroom-init-user.service. Config is in the systemd
  drop-in, not init-user defaults, so protect_recent stays 4.
- Verify after restart: /health for config, /stats for the four counters
  (subagent_cap_rewrites, cache_reconciliation with ttl_expiry_colds,
  abstract_vs_keep_warm_arm), and grep the proxy log for the auto-touch ENABLED
  line and any ERROR.
- The write cost model, for any future pruning or caching work: read 0.1x, write
  1.25x on 5m or 2.0x on 1h, all scaled to dollars by the model's input price.
  Warm-content compression break-even is about 11.5 times suffix over saving on
  5m (19 on 1h), which collapses to zero at a bust. Compress at the frontier and
  at busts, never deep-warm mid-conversation.
